# Инструкции агента

Читайте README.md. Это действующий мост TikTok → Sheets → Binom → Lemonad с обратными статусами ПП. Общайтесь по-русски, коротко сообщайте результат и проверки. Настройки должны быть доступны в браузере; руководство — по кнопке «?».

## Рабочий процесс

- Редактируйте central/, затем build.py. Не исправляйте только dist/action.php.
- Для логики/безопасности запускайте bash scripts/check.sh. UI проверяйте в браузере, включая клавиатуру и узкий экран.
- Не создавайте реальные лиды, клики и конверсии ради технических тестов без явного запроса. Используйте заглушки и временные БД.
- Не переспрашивайте уже данное разрешение. Отличайте готовность серверного кода от проверки всей цепочки ПП/Sheets/TikTok.
- Commit/push/deploy выполняйте по поручению пользователя. Push main автоматически деплоится после зелёных проверок; не публикуйте частично готовый код.

## Инварианты

- Проверяйте владельца на сервере. Баер не читает и не меняет чужие entities/leads; администратор видит всё.
- Дедупликация: buyer/owner + TikTok Lead ID, включая legacy namespace. ID и телефоны — строки, не float/JS Number.
- Snapshot заявки неизменяем. Смена связки не меняет принятые лиды.
- Подтверждённый clickid до вызова ПП. uclick не заменяет clickid.
- Таймаут и HTTP 200 без ожидаемого тела не означают успех. Не повторяйте неопределённые внешние запросы автоматически.
- SENT — приём, не апрув. CRM-статус задаётся постбэком ПП.
- Постбэк аккаунта: clickid + snapshot.route.partner. Посторонние игнорируются, неоднозначные сохраняются для проверки. Старые per-route URL остаются совместимыми.
- Polling SENT не enqueue/send лид повторно. Скачиваемый и копируемый Apps Script берутся из одной сборки.
- Сортировка до пагинации, SQL allowlist. Формат H:i:s d.m.Y, Europe/Moscow по умолчанию; личный выбор Europe/Moscow или UTC. База/API сохраняют UTC.
- Lucide SVG локальные с лицензией. Подсказки работают мышью/клавиатурой и закрываются при уходе и Escape.

## Публикация и деплой

Репозиторий публичный. Не коммитьте .private/, реальные конфиги, архивы, Excel, SQLite, master.key, SSH-ключи, токены, пароли и персональные данные. Root .gitignore разрешает только исходники и документацию. Проверяйте список файлов перед коммитом. Секреты деплоя — только GitHub production secrets, не логи.

Публикуется только central/dist/action.php. Не заменяйте web-root целиком: там privacy.html пользователя. Не меняйте другие сайты, Nginx/TLS без необходимости. Сначала бэкап, пауза и dispatch.lock, затем атомарная замена, перезапуск и health-check. Миграции добавочные; откат кода не откатывает БД. При ошибке честно сообщите статус.

Root не должен открывать/создавать/chown файлы управления в каталоге, доступном для записи leadbridge. Используйте защищённый /var/lib/lead-bridge-control, проверяйте права/ссылки и запускайте тесты безопасности деплоя.
